FontHandler

让 Windows 字体看着更舒畅

基于 GaspHack 技术，让 Windows 原生渲染出类似 MacType 的清晰效果，且兼容性更好。

由于 GaspHack 技术和 Windows 渲染方式的问题，暂建议 Windows 10 1709+ 用户使用

下载 源代码 使用文档

免安装单文件 exe · 无需预装 Python · Windows 7 SP1 及以上

核心特性

GaspHack 补丁生成

按字号切换 hinting 与网格拟合参数，字形轮廓不变。TTC 原地处理，无需拆分重组。

系统字体热替换

直接替换系统字体，文件被占用时自动放入重启队列，不强制关闭进程。

自动备份与一键还原

替换前自动备份原始文件与安全描述符，随时可完整还原，无需手动 takeown。

TrustedInstaller 权限管理

替换后自动将字体所有者归还 TrustedInstaller，防止登录界面字体异常。

重启队列与自检

被占用文件排队等下次开机替换，登录后自动清理缓存、校验权限。

免安装单文件

一个 exe 搞定一切，无需预装 Python 或其他运行时，下载即用。
